# PoE Price Check

Price checking overlay for **Path of Exile** on Windows: hover an item, press `Ctrl+D`, see the
listings of the official trade site, with a poe.ninja estimate.

**[Download the latest release](https://github.com/Shhu/poe-pricecheck/releases/latest)** ·
[Presentation page](https://shu-app.com/poe-pricecheck/)

One executable, nothing to install; the program offers its own updates from the releases here.
Unofficial tool, not affiliated with or endorsed by Grinding Gear Games.
